# Changelog

All notable changes to **WordDrop** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## <span style="color: #6200EE; font-weight: bold;">[1.0.0]</span> — 2026-10-31

### <span style="color: #00C853; font-weight: bold;">Added</span>
- **Core Learning Engine:** 120 structured levels from A1 to C2, with spaced repetition and contextual word usage.
- **Grammar Templates:** 60+ advanced grammar patterns with full explanations and AI-checked sentence generation.
- **AI Integration:** Real-time grammar checking, pronunciation coaching (phoneme-level in Uzbek), and IELTS band estimation.
- **Competitive Play:** 1v1 real-time duels with 4 modes (vocabulary, listening, grammar, templates) and a seasonal league system.
- **IELTS Mock Exams:** Full simulation of Reading, Listening, Writing, and Speaking with timers and auto-scoring.
- **3D Virtual Room:** Personal study space with customizable furniture and items purchasable using WordCoin.
- **Authentication:** Secure login via email/password and Google OAuth 2.0.
- **Gamification:** WordCoin economy, daily streaks, level system, and 12 unlockable achievements.
- **Localization:** Fully native Uzbek interface.
- **Initial Public Release:** Launched at [worddrop-app.uz](https://www.worddrop-app.uz).

### <span style="color: #FFAB00; font-weight: bold;">Changed</span>
- **UI/UX:** Complete redesign of the onboarding flow, dashboard, and profile screens.
- **Performance:** Optimized 3D rendering and reduced initial page load time by 40%.
- **Security:** Enhanced Row-Level Security (RLS) policies for all database tables.

### <span style="color: #D50000; font-weight: bold;">Fixed</span>
- Resolved an issue where the pronunciation feedback failed to load on Safari browsers.
- Fixed a rare bug causing duels to disconnect if a player refreshed the page.
- Corrected the streak calculation logic during daylight saving time transitions.

## <span style="color: #6200EE; font-weight: bold;">[0.9.0]</span> — 2026-08-15

### <span style="color: #00C853; font-weight: bold;">Added</span>
- **Duel Mode Beta:** Introduced real-time 1v1 battles with the first two modes (vocabulary and grammar).
- **AI Grammar Checker:** Integrated AI-powered sentence analysis and feedback.
- **WordCoin System:** Implemented the virtual currency for the 3D room store.
- **Profile & Settings:** Added user profiles, dark mode toggle, and notification settings.

### <span style="color: #FFAB00; font-weight: bold;">Changed</span>
- **Design System:** Migrated to a new color palette and typography (Bricolage Grotesque and Plus Jakarta Sans).
- **Audio Engine:** Switched to a more reliable audio playback system for listening exercises.

### <span style="color: #D50000; font-weight: bold;">Fixed</span>
- Fixed the memory leak in the 3D room rendering loop.
- Fixed an issue where the progress bar did not update after completing a level.
