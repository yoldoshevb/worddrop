# Security Policy

## Supported Versions

We take security seriously at WordDrop. Currently, the following versions are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please send an email to **bexruzyoldoshev@yahoo.com**.

Please include the following details in your report:
- The type of vulnerability (e.g., XSS, SQL Injection, Auth Bypass).
- A detailed description of the issue and the steps to reproduce it.
- Any potential impact or exploit scenario.
- (Optional) Suggestions for fixing the vulnerability.

### What to expect

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Investigation:** We will investigate and provide an initial assessment within **5 business days**.
- **Resolution:** If the vulnerability is confirmed, we will work on a fix and keep you updated on our progress. We will credit you for the discovery (unless you prefer to remain anonymous).

We ask that you do not publicly disclose the vulnerability until we have had a chance to address it. Thank you for helping keep WordDrop and its users safe!
